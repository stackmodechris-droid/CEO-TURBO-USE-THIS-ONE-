# Animation Creation Prompt - Office Transformation Service

**Goal:** Create engaging, professional animations that showcase the office transformation process for use on the website, social media, and ads.

---

## ANIMATION 1: Before/After Office Transformation

**Format:** 15-20 second loop
**Style:** Clean, professional, modern
**Use:** Website hero, social media, Meta ads

**Scene Description:**
1. **Start (0-3s):** Empty, dark office space with bare walls, no furniture, scattered boxes
2. **Middle (3-12s):** Fast-motion transformation showing:
   - Walls being framed and finished
   - Security cameras appearing on walls
   - Network cables being routed neatly
   - Desks and computers being assembled
   - Lights turning on
   - Clean, organized space emerging
3. **End (12-15s):** Bright, modern office with people working, cameras visible, clean aesthetic
4. **Loop:** Seamless transition back to start

**Visual Style:**
- Color palette: Dark grays → bright whites/turbo accent colors
- Smooth transitions, no jarring cuts
- Professional lighting
- Show transformation as magical but realistic

**Text Overlays (optional):**
- "Empty Space" → "Turnkey Office"
- "One-Time Pricing"
- "Atlanta Metro"

**Style:** Icon-based, clean, minimal

## TECHNICAL SPECIFICATIONS

**File Formats:**
- Primary: MP4 (H.264, 30fps)
- Secondary: GIF (for email/social)
- WebM (for web optimization)

**Resolutions:**
- Desktop: 1920x1080 or 1280x720
- Mobile: 1080x1920 (vertical)
- Square: 1080x1080

**File Sizes:**
- Under 2MB for web use
- Under 5MB for high-quality versions

**Color Palette:**
- Primary: Turbo accent color (from brand)
- Secondary: White, light grays
- Accent: Green for pricing comparisons

**Typography:**
- Clean, sans-serif fonts
- Large, readable text
- High contrast
