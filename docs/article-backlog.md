# Article backlog (used by the 3×/week article routine)

The routine takes the **first unchecked** topic, writes one guide in `src/content/guides.ts` (same `Guide` shape:
question-led H2s, a 40–60 word direct answer under each, a table where it helps, 3+ FAQs, 3 related links to real pages),
adds a headline to `HEADLINES` in `scripts/guide-images.mjs`, runs `node scripts/guide-images.mjs`, `npm test` and `npm run build`,
ticks the box here, and opens a PR. Rules: original, accurate and useful — no filler, no invented stats or reviews; link to
the shop or the free check only where it fits naturally.
